## 🔍 Overview

FlashMind is a full-stack intelligent flashcard application that leverages AI to convert any PDF document into a comprehensive set of study flashcards. Built on proven cognitive science principles — **spaced repetition** and **active recall** — it helps students retain information long-term rather than cramming before exams.

A student uploads a PDF (lecture notes, textbook chapters, research papers), and the AI generates high-quality flashcards covering key definitions, concepts, relationships, worked examples, and edge cases. The app then intelligently schedules reviews using the **SM-2 spaced repetition algorithm**, showing difficult cards more frequently and mastered cards less often.

## ✨ Features

### 🤖 AI-Powered Card Generation

- Card states: `NEW`, `LEARNING`, `STRONG`, `MASTERED`, `SHAKY`

- Search decks by title
- Browse all decks sorted by last studied
- See mastered, shaky, and due card counts per deck

### 🎨 Delightful UI
- Smooth 3D card flip animation
- Dark theme with clean minimalist design
- Animated transitions between cards during study sessions
- Toast notifications for all actions
- Fully responsive design

### 🔐 Authentication & Security
- JWT-based stateless authentication
- BCrypt password hashing
- Role-based access control (USER, ADMIN)
- Protected routes on frontend

## 🗄 Database Schema

```sql
-- Users table
CREATE TABLE users (
    id BIGSERIAL PRIMARY KEY,
    email VARCHAR UNIQUE NOT NULL,
    name VARCHAR NOT NULL,
    password VARCHAR NOT NULL,
    role VARCHAR DEFAULT 'USER',
    streak INT DEFAULT 0,
    last_active DATE,
    created_at TIMESTAMP DEFAULT NOW()
);

-- Decks table
CREATE TABLE decks (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT REFERENCES users(id),
    title VARCHAR NOT NULL,
    subject VARCHAR,
    pdf_url VARCHAR,
    card_count INT DEFAULT 0,
    created_at TIMESTAMP DEFAULT NOW(),
    last_studied TIMESTAMP
);

-- Cards table
CREATE TABLE cards (
    id BIGSERIAL PRIMARY KEY,
    deck_id BIGINT REFERENCES decks(id),
    front TEXT NOT NULL,
    back TEXT NOT NULL,
    card_type VARCHAR DEFAULT 'CONCEPT'
);

-- Card Progress table (SM-2 data)
CREATE TABLE card_progress (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT REFERENCES users(id),
    card_id BIGINT REFERENCES cards(id),
    ease_factor DOUBLE DEFAULT 2.5,
    interval_days INT DEFAULT 1,
    repetitions INT DEFAULT 0,
    next_review_date DATE DEFAULT NOW(),
    last_reviewed TIMESTAMP,
    UNIQUE(user_id, card_id)
);

-- Review Logs table
CREATE TABLE review_logs (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT REFERENCES users(id),
    card_id BIGINT REFERENCES cards(id),
    rating INT,
    reviewed_at TIMESTAMP DEFAULT NOW()
);
```

## 🧮 SM-2 Spaced Repetition Algorithm

FlashMind implements the industry-standard **SM-2 algorithm** for optimal review scheduling.

### Rating Scale (0-5)
| Rating | Label | Meaning |
|--------|-------|---------|
| 0 | Forgot | Complete blackout |
| 2 | Hard | Incorrect but remembered after hint |
| 3 | Good | Correct with difficulty |
| 5 | Easy | Perfect recall |

### Algorithm Logic
```
If rating < 3 (failed):
    repetitions = 0
    interval = 1 day

If rating >= 3 (passed):
    If repetitions == 0: interval = 1
    If repetitions == 1: interval = 6
    If repetitions > 1:  interval = round(interval × easeFactor)
    repetitions += 1

easeFactor = easeFactor + (0.1 - (5-rating) × (0.08 + (5-rating) × 0.02))
easeFactor = max(1.3, easeFactor)  // floor at 1.3

nextReviewDate = today + interval days
```

### Mastery Labels
| Label | Condition |
|-------|-----------|
| NEW | Never reviewed |
| LEARNING | interval < 7 days |
| STRONG | interval >= 7 days |
| SHAKY | easeFactor < 2.0 |
| MASTERED | interval >= 21 days |

## 🚀 Getting Started

### Prerequisites
- Java 21+
- Maven 3.8+
- Node.js 18+
- npm 9+
- PostgreSQL (local) or Neon account

### Backend Setup

```bash
# Clone the repository
git clone https://github.com/your-username/flashcard-engine.git
cd flashcard-engine

# Configure application.properties
# Edit src/main/resources/application.properties with your DB credentials

# Build and run
mvn spring-boot:run
```

### Frontend Setup

```bash
# Clone the repository
git clone https://github.com/your-username/flashcard-frontend.git
cd flashcard-frontend

# Install dependencies
npm install

# Create .env file
echo "VITE_API_URL=http://localhost:8080" > .env

# Run dev server
npm run dev
```

App will be running at `http://localhost:5173`

## ☁️ Deployment

### Database — Neon (Free PostgreSQL)
1. Sign up at [neon.tech](https://neon.tech)
2. Create project → copy JDBC connection string
3. Format: `jdbc:postgresql://HOST/neondb?sslmode=require`

### Backend — Render (Free)
1. Sign up at [render.com](https://render.com)
2. New Web Service → connect GitHub repo
3. Build command: `mvn clean package -DskipTests`
4. Start command: `java -Xms256m -Xmx512m -jar target/flashcard-engine-0.0.1-SNAPSHOT.jar --spring.profiles.active=prod`
5. Add all 5 environment variables
6. Deploy

### Frontend — Vercel (Free)
1. Sign up at [vercel.com](https://vercel.com)
2. Import GitHub repo
3. Framework: Vite
4. Add `VITE_API_URL` environment variable
5. Deploy
